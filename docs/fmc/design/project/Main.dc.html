Claude in Revit

Formcraft's fork of the Revit MCP server. Claude builds and checks the kit (families, chain tests, QA) and reads live models, inside the folder rules of the Formcraft BIM Manual, from a pane docked beside the Project Browser.

Guarded files
Create, save and archive only in WIP and staging. Dry run first, nothing deleted, every action logged.
Family builder
Data-shell families from the kit's specs in batches of 25, then a load test in the chain-test project.
Live-model lock
On live projects Claude reads and reports. Modelling stays with assessed modellers.
